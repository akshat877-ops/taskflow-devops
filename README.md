# TaskFlow — 3-Tier DevOps Platform

## Overview
TaskFlow is a learning project designed to demonstrate an end-to-end
DevOps workflow using a containerized task-management application.

## Planned Application Architecture
- Frontend: React with Nginx
- Backend: Node.js REST API
- Database: PostgreSQL

## Planned DevOps Stack
- Version Control: Git and GitHub
- CI/CD: GitHub Actions, Jenkins, GitLab CI
- Containers: Docker
- Container Registry: Amazon ECR
- Orchestration: Kubernetes
- Infrastructure as Code: Terraform
- GitOps: Argo CD
- Monitoring: Prometheus and Grafana
- Automation: Bash scripting
- Cloud: AWS

## Security and Cost Controls
- Never commit private keys, passwords or credentials.
- Use a cost-conscious AWS architecture.
- Remove temporary resources when they are no longer needed.
